Endpoints

Each endpoint is its own independent OpenVPN listener with its own port, protocol, and cipher — add one on port 443/TCP to blend in as ordinary HTTPS, or spread clients across a few for redundancy. Every client can connect through any endpoint you create.

Servers

Each server runs its own agent with its own PKI — a client certificate issued on one server is cryptographically meaningless on another, so no one, including the people you issue certificates to, can pick which exit IP they land on. Install the agent on any box you control and add it here.
